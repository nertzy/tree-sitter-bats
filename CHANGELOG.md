# Changelog

Notable changes to `tree-sitter-bats` are documented here.

## [Unreleased]

### Added

- Added the repository scaffold generated by `tree-sitter init`, with C, Go, Node.js, Python, Rust, and Swift bindings.
- Added `test_block` nodes for Bats `@test` definitions, with `name` and `body` fields, by extending tree-sitter-bash 0.25.1.
- Added CI that parses the `.bats` files of public Bats suites, with known failures listed in `script/known-failures.txt`.
- Added `test_marker_comment` nodes for the `# @test` comment that makes Bats run a function as a test, as in `name() { # @test`.
- Added `queries/highlights.scm` for Bash and Bats syntax, with highlight tests and a check that no node gets two highlight captures.

### Fixed

- Fixed `[ ... ]` tests merging with later redirected commands and a following `[ ... ]` into one `test_command` ([tree-sitter-bash#316](https://github.com/tree-sitter/tree-sitter-bash/issues/316)).
- Fixed herestrings after a file or heredoc redirect, as in `cat > file <<<"text"`, producing an `ERROR` ([tree-sitter-bash#232](https://github.com/tree-sitter/tree-sitter-bash/issues/232)).
